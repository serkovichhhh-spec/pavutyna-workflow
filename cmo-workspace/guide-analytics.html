Як змінити рекламу

  1. Оптимізатор щопонеділка пропонує до 3 рішень у «Дашборд → Рішення». У кожному є готові команди: було → стане.
  2. Ти погоджуєш рішення: пишеш у новому чаті проєкту PAVUTYNA CMO Виконай рішення <id>. Можна й своїми словами: «зменш бюджет PMax-7 до 120».
  3. Claude ставить зміну в чергу. База перевіряє запобіжники: якщо зміна їх порушує, вона відхиляється з поясненням.
  4. Скрипт Google Ads виконує її протягом години. Щоб застосувати одразу, натисни «Запустити» в кабінеті. Для кожної зміни зберігається «було → стало».

Встановлення скриптів

Робиться один раз. Файли скриптів із ключами доступу є в чаті проєкту від 09.11. Нікому їх не пересилай: ключ дає право писати в базу.

1. Google Ads Script

  1. Google Ads → кабінет 6825129974 «ТОВ ПАВУТИНА. НЕТ» → Інструменти → Масові дії → Скрипти → «+» → «Новий скрипт».
  2. Назва: Pavutyna · CMO Space sync. Замінити весь код вмістом файлу pavutyna-google-ads-script.js → «Зберегти».
  3. Натиснути «Авторизація» → вибрати свій Google-акаунт → «Дозволити». Це може зробити тільки людина.
  4. «Запустити» → «Запустити без попереднього перегляду». Перший запуск підтягує історію з січня 2025 і триває кілька хвилин.
  5. У списку скриптів, у колонці «Частота», вибрати «Щогодини».

2. GA4 Apps Script

  1. script.google.com під акаунтом із доступом до GA4 348106289 → «Новий проєкт», назва «Pavutyna · GA4 → CMO Space».
  2. Замінити код вмістом pavutyna-ga4-apps-script.js → «Зберегти».
  3. Зліва «Служби» (+) → Google Analytics Data API → «Додати».
  4. Угорі вибрати функцію setup → «Виконати» → дозволити доступ. Вона завантажить історію і створить запуски на 06:20 і 13:20.

Якщо щось зламалось

Аналітик пише «синхронізація не працює»

Відкрий Google Ads → Скрипти → «Pavutyna · CMO Space sync» → «Журнали» або Apps Script → «Виконання». Найчастіше причина — прострочена авторизація: натисни «Авторизація» ще раз.

Зміна не застосувалась

Попроси в чаті: «статус команд по рішенню <id>». Claude покаже, чи команду відхилили запобіжники, чи Google Ads повернув помилку, і що з цим робити.

Цифри не збігаються з кабінетом

Google Ads дорахувує конверсії до кількох днів назад, тому останні 35 днів щодня перезаписуються. Витрати за сьогодні — неповні.

Ключ потрапив не туди

Напиши в чаті «заміни ключ Google Ads / GA4». Старий вимкнеться, ти отримаєш новий, і його треба буде вставити в скрипт.
